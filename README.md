# c2-transformer

Transformer의 핵심 구성 요소를 구현하고, 언어 모델의 attention 및 생성 동작을 실습한 학습 기록입니다.

## 학습 내용

- Transformer 모델 구조
- Self-Attention의 계산 원리와 시각화
- Transformer block 구성
- Residual connection과 pre-normalization 실험
- BertViz를 이용한 attention 관찰
- 다음 토큰 생성과 temperature 변화 실험

## 구성

- `day01`: 모델 구조와 attention 기초
- `day02`: attention 심화 실습
- `day03`: Transformer block 및 미션
- `day04`: 사전학습 모델 활용과 attention 시각화
- `day05`: 텍스트 생성과 temperature 실험

## 실행

Jupyter Notebook 환경에서 노트북을 실행합니다. 시각화 결과는 HTML과 PNG 파일로 함께 확인할 수 있습니다.
